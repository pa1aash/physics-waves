# src/solver/

Solver definition and run harness. `equations.py` defines the rotating
shallow-water system in vector-invariant form; `harness.py` drives a run from a
config; `evp_hough.py` and `evp_stability.py` assemble the two eigenvalue
problems; `initial_conditions/` holds the per-case initial states. Stubs until
Session L5.
