# src/analysis/

Post-processing pipeline (blueprint §12), stages 2–11: derived diagnostics,
Hovmöller extraction, phase-speed and growth-rate fitting, spectral
decomposition, structure extraction, error norms, reanalysis processing and
result aggregation, plus the Hough and stability-EVP analyses. Each stage is
config-driven and never mutates raw data. Stubs until Session L6.
