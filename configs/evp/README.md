# configs/evp/

Eigenvalue-problem configs. `EVP-hough.yaml` sweeps the Hough-mode
eigenfrequencies of the divergent shallow-water system over Lamb's parameter and
azimuthal order (extension B). `EVP-jet-stability.yaml` solves the linear
stability eigenvalues about each zonal base state (extension C). Stubs created in
Session 00.
