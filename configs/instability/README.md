# configs/instability/

Run configs for the barotropic-instability campaign, `I-00` … `I-12`. `I-00` is
the Galewsky, Scott & Polvani (2004) anchor case; `I-01` … `I-12` sweep jet shear,
rotation rate, resolution and perturbation seed. Growth rates and dominant
wavenumbers are checked against the Rayleigh-Kuo diagnostic and the stability EVP.
Stubs created in Session 00.
