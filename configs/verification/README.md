# configs/verification/

Run configs for the verification campaign, `V-01` … `V-09`. These reproduce the
Williamson et al. (1992) spherical shallow-water benchmark cases plus the Läuter
et al. (2005) unsteady analytic solution (`V-09`). No experimental run begins
until the verification gate (blueprint §9.4) passes. Stubs created in Session 00;
numeric parameters are filled once the solver exists.
