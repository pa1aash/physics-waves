check_rh_dispersion
============================================================
Claim: c_ang = -2 Omega / [n(n+1)] for the nondivergent
barotropic vorticity equation linearised about rest.

Arm 1 - the linearised equation
------------------------------------------------------------
  zeta = nabla^2 psi for the metric streamfunction: exact zero
  v df/dy - (2 Omega/R^2) d_lambda psi: exact zero
  (the cos(phi) of beta cancels the 1/cos(phi) of v -- this is why the
   spherical phase speed depends on n alone, not on latitude)

Arm 2 - spherical-harmonic ansatz, solved for omega
------------------------------------------------------------
  (n, m) = (1, 1): omega = -Omega  expected -Omega  -> agrees
      c_ang = omega/m = -Omega   (negative: westward)
  (n, m) = (2, 1): omega = -Omega/3  expected -Omega/3  -> agrees
  (n, m) = (2, 2): omega = -2*Omega/3  expected -2*Omega/3  -> agrees
  (n, m) = (3, 1): omega = -Omega/6  expected -Omega/6  -> agrees
  (n, m) = (3, 2): omega = -Omega/3  expected -Omega/3  -> agrees
  (n, m) = (3, 3): omega = -Omega/2  expected -Omega/2  -> agrees
  (n, m) = (4, 2): omega = -Omega/5  expected -Omega/5  -> agrees
  (n, m) = (5, 4): omega = -4*Omega/15  expected -4*Omega/15  -> agrees
  (n, m) = (6, 1): omega = -Omega/21  expected -Omega/21  -> agrees
      c_ang = omega/m = -Omega/21   (negative: westward)

Arm 3 - the sign, derived from the displacement argument
------------------------------------------------------------
  beta-plane: c = -beta/k**2  expected -beta/k^2  -> agrees
  beta > 0 and k^2 > 0, so c < 0 unconditionally: westward, not by choice.
  spherical: -beta/K^2 = -2*Omega*R*cos(phi)/(n*(n + 1)), c_ang R cos(phi) = -2*Omega*R*cos(phi)/(n*(n + 1))
  the two agree identically: yes
